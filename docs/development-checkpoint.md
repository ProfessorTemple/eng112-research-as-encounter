## How to read this tracker

- **Implemented:** code is committed, not necessarily browser-verified.
- **Targeted checks:** syntax or isolated logic checks have been executed; not a substitute for end-to-end testing.
- **Research only:** isolated experiments on synthetic data; no student-facing AI deployment.
- **Release gate:** evidence required before changing the stable classroom notebook.

No single percentage is assigned to an open-ended pedagogical project. Development readiness and intellectual ambition are different dimensions.

## Non-negotiable release gates

- Student authorship, privacy, explicit choices and permission boundaries remain intact.
- No mandatory intellectual profile, mastery score, hidden learner classification, auto-written essay, automatic transmission of student prose, or automatic publication.
- Suggested concepts and relationships remain provisional, grounded in actual words and accurately attributed resources; students can decline or continue independently.
- No promotion from experimental to stable solely because code exists or isolated checks pass. End-to-end verification and instructor approval are required.
- Maintain a safe way back to the stable notebook and a locally exportable backup.

## Manual accessibility review before a classroom pilot

- Keyboard-only: start/continue, skip to active work, open/close optional help, navigate to and from a source or thesis, draft, back up and export. Confirm focus is visible, logical, never trapped or obscured.
- Screen readers: Safari with VoiceOver and Windows with NVDA or another supported reader. Confirm names, headings, input instructions, save failure announcements and quiet typing. Review dynamic reflection disclosures without assuming an automated pass is enough.
- Zoom and reflow: 200% and 400% browser zoom, 320 CSS-pixel width, long notes, enlarged text spacing, forced colors, reduced motion and portrait orientation. Check that controls remain reachable without horizontal page scrolling, with an exception for genuinely two-dimensional content.
- Cognitive access: first-time and interrupted-session walkthroughs using synthetic work. Observe whether students can locate the next useful action, decline assistance, resume writing and find backup/export without extra decisions. Invite feedback rather than infer cognitive or disability profiles.
- Validate accessible exported document headings, reading order, alt text and PDF limitations separately. Obtain instructor approval before promotion; do not claim ADA or WCAG compliance based on the browser audit alone.
